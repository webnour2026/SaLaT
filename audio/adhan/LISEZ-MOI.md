# Fichiers Adhan

Aucun enregistrement n'est fourni : les Adhans commerciaux sont protégés.
Déposez ici des fichiers **libres de droits ou sous licence**, en MP3, avec exactement ces noms :

| Choix dans l'appli | Fichier        |
|--------------------|----------------|
| Makkah             | makkah.mp3     |
| Madinah            | madinah.mp3    |
| Maroc              | morocco.mp3    |
| Égypte             | egypt.mp3      |
| Adhan 1 / 2 / 3    | adhan1.mp3, adhan2.mp3, adhan3.mp3 |

Si un fichier manque, l'appli joue un bip et affiche un message.
Conseil : 64–96 kbit/s mono suffit (1–2 Mo par Adhan). Les fichiers sont mis en cache au premier usage.
Pour ajouter un Adhan, ajoutez une entrée dans `ADHANS` (js/adhan.js).
